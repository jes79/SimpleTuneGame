## 실행 방법

```
1. Unity Hub → Add → C:\...\SimpleTuneGame\TURNORI
2. Editor 2022.3.62f1로 열기 (최초 임포트에 수 분 소요)
3. Assets/Scenes/Story.unity → Play
```

전투만 확인하려면 `Stage1.unity` 또는 `Stage2.unity`를 직접 열면 됩니다.
단, `Field`를 거치지 않고 `Stage`를 바로 열면 `PlayerPrefs`에 좌표가 없어
승리/패배 후 `Field`에서 원점(0,0)에 배치됩니다.

## 빌드 전 필수 작업

현재 상태로는 **빌드본이 정상 동작하지 않습니다.** 아래 두 가지가 선행되어야 합니다.

### 1. 빌드 씬 목록 등록

`ProjectSettings/EditorBuildSettings.asset`의 씬 목록이 비어 있습니다.

```yaml
m_Scenes: []
```

`SceneManager.LoadScene("Field")`, `LoadScene("Stage1")` 등이 전부 실패하므로
`File > Build Settings`에서 다음 순서로 추가해야 합니다.

```
0  Assets/Scenes/Story.unity
1  Assets/Scenes/Field.unity
2  Assets/Scenes/Stage1.unity
3  Assets/Scenes/Stage2.unity
```

### 2. 태그 등록 확인

`ProjectSettings/TagManager.asset`의 커스텀 태그 목록도 비어 있습니다.

```yaml
tags: []
```

그런데 코드와 씬은 커스텀 태그 3개에 의존합니다.

| 태그 | 사용처 |
|---|---|
| `Player` | `Player.SpecialAttackCT`, `Monster.Start`, `CameraController.Awake`, `fight.OnTriggerEnter2D` |
| `Monster` | `Player.Start` |
| `Status` | `GameManager.Start` |

정의되지 않은 태그로 `GameObject.FindGameObjectsWithTag`를 호출하면
`UnityException: Tag: ... is not defined`가 발생합니다. 에디터에서 Play가 정상
동작한다면 태그는 로컬에만 등록되고 `TagManager.asset`이 커밋되지 않은 상태일 수 있습니다.
**프로젝트를 새로 클론한 환경에서 가장 먼저 확인해야 할 항목입니다.**

`Project Settings > Tags and Layers`에서 `Player`, `Monster`, `Status`를 추가한 뒤
`TagManager.asset`을 커밋하세요.

### 3. 선택: 프로젝트 메타데이터

```yaml
companyName: DefaultCompany
productName: My project
bundleVersion: 0.1
```

기본값 그대로이므로 배포 전 `TURNORI` 등으로 교체가 필요합니다.

## 버전 관리

`.gitignore`는 공식 Unity 템플릿을 사용하며 `Library/`, `Temp/`, `Logs/`,
`UserSettings/`, `*.csproj`, `*.sln`을 제외합니다. 적절한 설정입니다.

현재 커밋 이력:

```
4d6fb24 FirstUpload
f5a8b90 Update .gitignore
8c43897 Initial commit
```

> `.meta` 파일은 반드시 함께 커밋해야 합니다(현재 포함되어 있음).
> 또한 `Sound/`의 대용량 WAV 때문에 저장소가 무거우므로
> Git LFS 도입 또는 미사용 파일 제거를 검토할 만합니다
> ([06. 에셋 구성](06-에셋-구성.md#정리-대상-후보) 참고).

## 테스트

`com.unity.test-framework`가 설치되어 있지만 테스트 어셈블리나 테스트 코드는 없습니다.
순수 C# 클래스인 `CoolTime`과 `CSVReader`는 `MonoBehaviour` 의존이 없거나 얕아
단위 테스트를 붙이기 쉬운 지점입니다
(`CoolTime`은 `Time.time` 의존을 주입 가능하게 바꾸면 테스트 가능).
