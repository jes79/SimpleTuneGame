### TextMeshPro 패키지가 사라진 이유

Unity 6부터 TextMeshPro가 **uGUI 패키지에 통합**되어 `com.unity.textmeshpro`가
목록에서 빠졌습니다. 대미지 숫자(`DamegeCanvas.prefab`)가 쓰는 `TextMeshProUGUI`는
`com.unity.ugui` 2.6.0이 제공하므로 동작에는 영향이 없습니다.
`Assets/TextMesh Pro/` 폴더(폰트 에셋·셰이더)는 그대로 남아 있습니다.

## 실행 방법

```
1. Unity Hub → Add → C:\...\SimpleTuneGame\TURNORI
2. Editor 6000.6.0f1로 열기 (최초 임포트에 수 분 소요)
3. Assets/Scenes/Story.unity → Play
```

**열어야 할 폴더는 저장소 루트가 아니라 그 안의 `TURNORI`입니다.**
루트(`SimpleTuneGame/`)를 열면 Unity가 거기를 새 프로젝트로 인식해
빈 `Assets/`, `Library/`, `ProjectSettings/`를 생성합니다. 그런 일이 생기면
Unity를 끄고 루트에 생긴 해당 폴더들을 지우면 됩니다 — `TURNORI/`는 영향받지 않습니다.

전투만 확인하려면 `Stage1.unity` 또는 `Stage2.unity`를 직접 열면 됩니다.
단, `Field`를 거치지 않고 `Stage`를 바로 열면 `PlayerPrefs`에 좌표가 없어
승리/패배 후 `Field`에서 원점(0,0)에 배치됩니다.

## 빌드 전 필수 작업

### 1. 빌드 씬 목록 등록 (완료)

`ProjectSettings/EditorBuildSettings.asset`에 씬 4개가 등록되었습니다 (커밋 `359e98e`).

```yaml
m_Scenes:
- enabled: 1
  path: Assets/Scenes/Field.unity
- enabled: 1
  path: Assets/Scenes/Story.unity
- enabled: 1
  path: Assets/Scenes/Stage1.unity
- enabled: 1
  path: Assets/Scenes/Stage2.unity
```

`SceneManager.LoadScene("Field")`, `LoadScene("Stage1")` 등이 빌드본에서도 동작합니다.

> 인덱스 0이 `Field`라서 빌드본은 **인트로를 건너뛰고 필드에서 시작**합니다.
> 스토리부터 시작하려면 Build Settings에서 `Story.unity`를 맨 위로 옮기세요.

### 2. 태그 등록 (완료)

`ProjectSettings/TagManager.asset`에 커스텀 태그 3개가 등록되었습니다.

```yaml
tags:
- Player
- Monster
- Status
```

코드와 씬이 의존하는 태그는 다음과 같으며, 등록된 목록과 정확히 일치합니다.

| 태그 | 사용처 |
|---|---|
| `Player` | `Player.SpecialAttackCT`, `Monster.Start`, `CameraController.Awake`, `fight.OnTriggerEnter2D` |
| `Monster` | `Player.Start` |
| `Status` | `GameManager.Start` |

이전에는 `tags: []`인 채로 커밋되어 있어, 새로 클론한 환경에서
`GameObject.FindGameObjectsWithTag` 호출 시
`UnityException: Tag: ... is not defined`가 발생할 수 있는 상태였습니다.
`MainCamera`와 `Untagged`는 Unity 내장 태그라 등록이 필요 없습니다.

### 3. 선택: 프로젝트 메타데이터

```yaml
companyName: DefaultCompany
productName: My project
bundleVersion: 0.1
```

기본값 그대로이므로 배포 전 `TURNORI` 등으로 교체가 필요합니다.
Unity 6 업그레이드에서도 이 값들은 바뀌지 않았습니다.

## 버전 관리

`.gitignore`는 공식 Unity 템플릿을 기반으로 하며 `Library/`, `Temp/`, `Logs/`,
`UserSettings/`, `*.csproj`, `*.sln`, `*.slnx`를 제외합니다.
`*.slnx`는 Unity 6이 생성하는 새 솔루션 파일 형식이라 업그레이드 시 추가했습니다.
