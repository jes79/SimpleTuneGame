## 전투

### GameManager

전투 씬의 중앙 매니저. `public static GameManager ins`로 전역 접근(`Awake`에서 무조건 대입).

**필드**

| 필드 | 타입 | 설명 |
|---|---|---|
| `D_Player` | `Dictionary<string, GameObject>` | 생존 플레이어. 키는 `"검사"`, `"신관"`, `"마법사"` |
| `L_Monster` | `List<GameObject>` | 생존 몬스터 |
| `PlayTurn` / `MonsterTurn` / `CurrTurn` | `bool` | 턴 상태 ([02. 아키텍처](02-아키텍처.md#상태-변수-3개의-역할) 참고) |
| `Player1~3`, `Monster1~3` | `GameObject` | 인스펙터 연결. `Start()`에서 컬렉션에 등록 |
| `Status` | `GameObject[]` | `Status` 태그 검색 결과 |
| `Turn`, `TurnTxt`, `TurnTime` | `Slider`, `Text`, `float` | 턴 게이지(기본 10초) |
| `GameOver`, `GameWin` | `GameObject` | 결과 캔버스. `Start()`에서 비활성화 |

**메서드**

| 메서드 | 설명 |
|---|---|
| `Win()` / `Over()` | `Field` 씬 로드. 결과 캔버스 버튼에서 호출 |
| `MonsterAttack()` | 코루틴. `MonsterTurn` 동안 2초 간격 라운드로빈 몬스터 공격 |
| `StatusShow()` | 3개 상태창의 Text 5개를 매 프레임 갱신 |

> `Start()`에 `Resources.Load("Player/...")` 기반 동적 생성 코드가 주석으로 남아 있습니다.
> `Resources/Player/` 프리팹 3개는 현재 씬에 직접 배치되어 쓰입니다.

### Player

**필드**: `Pdata`(PlayerData), `MagicAura`/`T_MagicAura`(마법진 프리팹·위치),
`Explosion`(특수공격 폭발), `DamegeCanvas`(피격 숫자), `OriPos`/`Back`(돌진 복귀 상태)

**메서드**

| 메서드 | 설명 |
|---|---|
| `NomalAttack()` | `CurrTurn == false`일 때만 `NomalAttackCT` 코루틴 시작 |
| `NomalAttackCT()` | 랜덤 몬스터로 돌진 → 거리 0.5 이하에서 `attack` 트리거 + 효과음 + `Monster.Damege(Pdata.Attack)` |
| `SpecialAttack()` | 동일한 턴 게이트 후 `SpecialAttackCT` 시작 |
| `SpecialAttackCT()` | 마법진 생성 → 2.5초 대기 → 폭발 생성. **대미지 없음**. 신관은 아군 위치에 생성 |
| `Sound()` | 직업별 `SoundManager.PlayAttackSound(index)` — 검사 8, 신관 4, 마법사 2 |
| `Damege(int)` | `Pdata.Hp` 차감, `damege` 트리거, 대미지 캔버스 생성. HP 0 이하 시 `D_Player`에서 제거 + `Destroy` |

`Monster` 배열은 `Start()`에서 `FindGameObjectsWithTag("Monster")`로 **한 번만** 캐시합니다.

### Monster

`Player`와 거울 구조. 차이점만:

- `Start()`에서 `Hp = Pdata.Hp; MaxHp = Pdata.MaxHp;`로 **로컬 복사** 후 로컬 `Hp`를 차감
- 특수 공격과 효과음 없음
- 공격 후 복귀 대기 시간이 0.03초 (`Player`는 0.3초)
- 턴 게이트 없음 — 호출 주체(`GameManager.MonsterAttack`)가 타이밍을 보장

### SoundManager

`[RequireComponent(typeof(AudioSource))]` 싱글톤. `AttackSound` 배열에서 인덱스로 골라
`PlayOneShot`. `instance`는 null일 때만 대입하지만 중복 인스턴스를 파괴하진 않습니다.

## 유틸

### CoolTime

`MonoBehaviour`가 아닌 순수 클래스(`new`로 생성). 0→`t`를 반복하는 톱니파 타이머.

```csharp
public float Timer(float t)
{
    if (CoolCnt + t <= Time.time) { CoolCnt = Time.time; Cooltime = 0; }
    Cooltime += Time.deltaTime;
    return Cooltime;
}
```

`void Start()`가 남아 있지만 `MonoBehaviour`가 아니라 호출되지 않습니다(무해).

### CSVReader

정적 클래스. `Resources`에서 `TextAsset`을 읽어 첫 줄을 헤더로,
나머지를 `Dictionary<string, object>`로 파싱합니다. 정규식으로 따옴표 안의 콤마를 보호하고
`int` → `float` 순으로 숫자 변환을 시도합니다.

```csharp
List<Dictionary<string, object>> data = CSVReader.Read("story");
string line = data[0]["대사"].ToString();
```

### Effect

`life`(기본 1초) 후 자신을 `Destroy`. 파티클·이펙트 프리팹의 자동 정리용.

### Fade

`Image`용과 `SpriteRenderer`용 페이드를 각각 제공합니다.

| 메서드 | 대상 | 방향 |
|---|---|---|
| `FadeIn(t)` | `Image` | 투명 → 불투명 |
| `FadeOut(t)` | `Image` | 불투명 → 투명 |
| `FadeIn2(t)` | `SpriteRenderer` | 투명 → 불투명 |
| `FadeOut2(t)` | `SpriteRenderer` | 불투명 → 투명 |

`t`는 완전히 변하는 데 걸리는 초입니다(`alpha += deltaTime / t`).

## 스토리

### TextManager

`Start()`에서 페이드 인/아웃과 CSV 로드를 수행하고 첫 대사를 출력.
`Update()`의 좌클릭마다 다음 줄 출력 + `witch` Animator의 `tell` 트리거 발동.
줄이 끝나면 페이드 후 `Field` 로드.

## 필드

### PlayerMovement

```csharp
rb.linearVelocity = new Vector2(Input.GetAxis("Horizontal") * moveSpeed,
                                Input.GetAxis("Vertical")   * moveSpeed);
FindObjectOfType<PlayerAnimation>().SetDirection(direction);
```

`Start()`에서 `PlayerPrefs`의 `PlayerX`/`PlayerY`로 위치를 복원합니다
(키가 없으면 0 → 원점에서 시작).

> Unity 6 업그레이드(`7f10411`) 때 API Updater가 `rb.velocity`를
> `rb.linearVelocity`로 자동 치환했습니다. `Rigidbody2D.velocity`는 Unity 6에서
> 사용 중단되었습니다. 2022.3으로 되돌릴 경우 이 줄도 `velocity`로 돌아가야 합니다.
> 프로젝트 전체에서 Unity 6 API로 바뀐 코드는 이 한 줄뿐입니다.

### PlayerAnimation

이동 벡터의 각도를 8등분(45°)해서 애니메이션 상태 이름을 직접 `anim.Play()` 합니다.

```csharp
staticDirections = { "Static N", "Static NW", "Static W", "Static SW",
                     "Static S", "Static SE", "Static E", "Static NE" };
runDirections    = { "Run N", "Run NW", ... };
```

`DirectionToIndex()`는 `Vector2.SignedAngle(Vector2.up, dir)`에 22.5° 오프셋을 더해
반시계 방향 인덱스를 구합니다. 속도 크기가 0.01 미만이면 `lastDirection`을 유지한 채
정지 애니메이션으로 전환합니다.

### CameraController

`Awake`에서 `Player` 태그를 추적 대상으로 잡고, `LateUpdate`에서 `Vector3.Lerp`로
부드럽게 따라가며 `minX/maxX/minY/maxY`로 맵 밖을 보지 못하게 클램프합니다.

### TrapSpawn

`Start()`에서 `Fight` 프리팹 3개를 `Random.Range(-3f, 3f)` 오프셋으로 생성하고
자신의 자식으로 붙입니다.

### fight

전투 진입 트리거.

```csharp
void Start() {
    fade = GameObject.Find("fade").GetComponent<Fade>();
    GetComponent<SpriteRenderer>().color = new Color(1, 1, 1, 0f);  // 투명화
}
OnTriggerEnter2D(col) → col.tag == "Player" → FadeAction()
```

`FadeAction()`은 페이드 인 → 1초 대기 → 페이드 아웃 후
현재 좌표를 `PlayerPrefs`에 저장하고 `"Stage" + Random.Range(1, 3)`을 로드합니다.

### NPC

`OnCollisionEnter2D`에서 `can` 캔버스를 켜고 `OnCollisionExit2D`에서 끕니다.

### HideTilemapColliderOnPlay

`Start()`에서 `TilemapRenderer`를 비활성화해 콜라이더용 타일맵을 숨깁니다.
현재 어떤 씬에서도 사용되지 않습니다.

## 데이터

### PlayerData / MonsterData

둘 다 `ScriptableObject` + `[CreateAssetMenu]`.
에디터 메뉴 `Assets > Create > Data > PlayerData` / `Data/MonsterData`로 생성합니다.

| PlayerData | MonsterData |
|---|---|
| `Pname`, `Job` | `Mname`, `Job` |
| `Hp`, `MaxHp` | `Hp`, `MaxHp` |
| **`Attack`** | **`Damege`** |
| `Level`, `Mp`, `MaxMp`, `Exp` | `Level`, `Mp`, `MaxMp`, `Exp` |

공격력 필드 이름만 다르고 나머지는 동일합니다. 실제 값은
[05. 데이터와 밸런스](05-데이터와-밸런스.md)에 정리되어 있습니다.
