# 06. 에셋 구성

## 용량 분포

프로젝트 전체 약 102MB (`Library/` 제외).

| 폴더 | 용량 | 비고 |
|---|---:|---|
| `Sound/` | 70MB | 미사용 WAV 4개가 대부분 |
| `JMO Assets/` | 18MB | 외부 — Cartoon FX |
| `CGDATA/` | 6.0MB | 자체 — 스프라이트, 폰트 |
| `TextMesh Pro/` | 3.6MB | 패키지 리소스 |
| `Scenes/` | 3.2MB | Field 타일맵 비중 큼 |
| `Isometric Nature Pack/` | 1.5MB | 외부 — 타일 |
| `Witch/` | 487KB | 외부/변형 — 8방향 마녀 스프라이트 |
| `Prefabs/` | 444KB | 자체 |
| `faimg/` | 324KB | 타일 팔레트 |
| `Script/` + `Data/` | 85KB | 자체 코드 |

## 자체 제작 / 교육용 리소스

### `CGDATA/`

전투 캐릭터와 UI 리소스가 모여 있습니다.

| 종류 | 파일 |
|---|---|
| 캐릭터 시트 | `fighter.png`, `priest.png`, `witch.png`, `char_25z.png` |
| 몬스터 시트 | `puyo.png`, `eye.png` |
| 일러스트 | `WITCH_01~04.png` (스토리 씬), `BG001.bmp`, `Map1.bmp` |
| UI | `status.png`, `command.png`, `popup.png`, `popup_parts.png`, `TurnEnd.png`, `Cursor.png`, `GAMEOVER.png` |
| 이펙트 | `Explosion.png`, `FireBall.png` |
| 장식 | `tree1.png`, `tree2.png`, `stone1.png`, `stone2.png`, `mal.png`, `npc_01.png`, `st50c.png` |
| 폰트 | `NEXON Lv2 Gothic.ttf` (2.4MB, 한글 UI용) |
| Animator | `witch_18`, `priest_18`, `fighter_18`, `puyo_0`, `eye_0`, `Explosion_0`, `char_25z_0`, `text` |

애니메이션 클립 명명 규칙은 `<캐릭터>_<동작>_<방향>.anim` 입니다.

- 플레이어: `*_idle_UR`, `*_attack_UR`, `*_damege_UR` (Upper-Right 방향)
- 몬스터: `*_idle_DL`, `*_attack_DL`, `*_demage_DL` (Down-Left 방향)

> `damege`/`demage` 표기가 캐릭터별로 섞여 있습니다. Animator 트리거 이름은
> `attack`, `damege`로 통일되어 있어 코드와는 맞습니다.

|---|---|

| `CFX_Magical_Source.prefab` | 마법진 (CFX 프리팹을 복사해 수정) |
| `Map1.prefab` | 전투 배경 |
| `tree1.prefab` | 배경 장식 |
| `puyo.prefab`, `eye.prefab` | 몬스터 (`Monster` 태그) |
| `WIN.prefab`, `GAMEOVER.prefab` | 결과 캔버스 |
| `Fade.prefab` | 전체 화면 페이드용 Image |

### `Resources/`

**런타임 경로 로드 대상만** 넣어야 하는 특수 폴더입니다.

| 경로 | 로드 방식 |
|---|---|
| `Resources/story.txt` | `CSVReader.Read("story")` → `Resources.Load` |
| `Resources/Player/swordman.prefab` | 현재는 씬에 직접 배치. `GameManager`의 `Resources.Load` 코드는 주석 처리 상태 |
| `Resources/Player/priest.prefab` | 같음 |
| `Resources/Player/witch.prefab` | 같음 |

플레이어 프리팹 3개는 경로 로드를 쓰지 않으므로 `Resources/` 밖으로 옮겨도 동작합니다
(그 편이 빌드 용량에 유리합니다 — `Resources/` 내용은 사용 여부와 무관하게 전부 빌드에 포함됩니다).

### `Sound/`

| 파일 | 용량 | 사용 |
|---|---:|---|
| `마린사운드_공격류-1~14.mp3` | 각 18~98KB | `SoundManager.AttackSound`에 연결 |
| `가을 천둥.wav` | 26MB | Stage1 씬에서 참조 |
| `메타 夢.wav` | 16MB | **미사용** |
| `빠라빠빠.wav` | 15MB | **미사용** |
| `요구르트 요들.wav` | 14MB | **미사용** |

미사용 WAV 3개가 45MB로, **프로젝트 용량의 약 44%**를 차지합니다.
BGM으로 쓸 계획이라면 MP3/OGG로 변환 + Streaming 로드 타입 설정을,
그렇지 않다면 삭제를 권합니다.

## 외부 에셋

### JMO Assets — Cartoon FX (Free)

파티클 이펙트 팩. 프리팹 50개(CFX / CFX2 / CFX3 / CFX4 시리즈)와 셰이더, 에디터 툴
(`CFXEasyEditor`)이 포함되어 있습니다.

실제 사용분:

| 프리팹 | 사용처 |
|---|---|
| `CFX_Magical_Source` | Stage1 마법진 (복사해 `Prefabs/`에 둠) |
| `CFX3_DarkMagicAura_A` | Stage2 마법진 |
| `CFX3_MagicAura_B_Runic`, `CFX3_MagicAura_D_Runic` | Stage2 마법진 |

나머지 47개와 데모 씬, 데모 스크립트 6개는 미사용입니다.

### Isometric Nature Pack

쿼터뷰 타일 에셋. 스프라이트시트 14장을 슬라이스한 서브 에셋 78개.
Field / Stage1 타일맵 구성에 사용합니다.

### Witch (캐릭터 팩)

8방향 마녀 스프라이트 39장과 애니메이션 클립 16개(`Run N/NE/E/SE/S` + `Static` 계열).
`Scripts/` 하위의 `PlayerMovement`, `PlayerAnimation`, `CameraController`,
`HideTilemapColliderOnPlay`가 이 팩에 딸려온 코드이며 주석에 `MARKER`, `CORE`, `OPTIONAL`
같은 튜토리얼 표기가 남아 있습니다.

### `faimg/`

`st14b.png`, `st14c.png` 타일 시트와 서브 스프라이트, `New Palette.prefab`
(Tile Palette 에셋). 현재 씬에서 직접 참조되지는 않습니다.

## 정리 대상 후보

| 대상 | 절감 |
|---|---|
| 미사용 WAV 3개 (`메타 夢`, `빠라빠빠`, `요구르트 요들`) | 약 45MB |
| Cartoon FX 데모 씬·스크립트·미사용 프리팹 | 최대 17MB |
| `SampleScene.unity` | - (혼란 방지) |
| `HideTilemapColliderOnPlay.cs` | - (미사용 코드) |

`CFX_Magical_Source`, `CFX3_*Aura*` 계열의 의존 파일은 남겨야 합니다.
