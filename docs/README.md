# TURNORI 프로젝트 위키

Unity 2D 턴제 RPG 프로토타입 **TURNORI**의 개발 문서입니다.
저장소 루트(`SimpleTuneGame/`) 아래 Unity 프로젝트 본체는 `TURNORI/`에 있습니다.

## 한눈에 보기

| 항목 | 값 |
|---|---|
| Unity 버전 | 6000.6.0f1 (Unity 6) |
| 렌더 파이프라인 | Built-in (BiRP), 2D 스프라이트 기반 |
| 장르 | 필드 탐험 + 턴제 전투 RPG |
| 자체 스크립트 | 18개 (약 1,000 LOC) |
| 씬 | 5개 (`Story`, `Field`, `Stage1`, `Stage2`, `SampleScene`) |
| 출처 | 더조은게임아카데미 유니티반 교육 프로젝트 (2020-10-29, 강사 유건곤) |

## 빠르게 시작하기

1. Unity Hub에서 `TURNORI/` 폴더를 프로젝트로 추가 (Editor 6000.6.0f1 필요)
2. `Assets/Scenes/Story.unity`를 열고 Play — 인트로 대사 → 필드 → 전투 순으로 진행
3. 전투만 보려면 `Assets/Scenes/Stage1.unity`를 직접 열고 Play

**열어야 할 폴더는 저장소 루트가 아니라 그 안의 `TURNORI`입니다.** 루트를 열면 Unity가
거기를 새 프로젝트로 보고 빈 구조를 만들어 버립니다.

> 빌드를 막던 설정 문제(빌드 씬 목록, 커스텀 태그 등록)는 모두 해결되었습니다.
> 남은 과제는 코드 쪽 2건입니다 — [08. 알려진 이슈](08-알려진-이슈.md) 참고.
